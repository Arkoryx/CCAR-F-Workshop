# CCAR-F Exam Blueprint

**Claude Certified Architect – Foundations (CCAR-F)**

| Attribute | Value |
|---|---|
| Format | 60 questions, multiple-choice and multiple-response |
| Time | 120 minutes |
| Scoring | Scaled 100–1000; **720 to pass** |
| Cost | $125 USD per attempt |
| Delivery | Online-proctored or Pearson VUE test centre |
| Validity | 12 months |
| Prerequisites | None formally. Target candidate has ~6 months hands-on with the Claude API, Agent SDK, Claude Code, and MCP |
| Typical prep | 40–100 hours |

## Domains

| # | Domain | Weight | Modules |
|---|---|---:|---|
| 1 | Agentic Architecture & Orchestration | **27%** | 7 |
| 2 | Claude Code Configuration & Workflows | **20%** | 6 |
| 3 | Prompt Engineering & Structured Output | **20%** | 6 |
| 4 | Tool Design & MCP Integration | **18%** | 5 |
| 5 | Context Management & Reliability | **15%** | 6 |

30 task statements across the five domains.

### 1. Agentic Architecture & Orchestration — 27%
Design and implement agentic systems using Claude's API, including loop management,
orchestration patterns, guardrails, and the Claude Agent SDK.

### 2. Claude Code Configuration & Workflows — 20%
Configure Claude Code for development workflows; manage settings, hooks, permissions,
and integration with CI/CD pipelines.

### 3. Prompt Engineering & Structured Output — 20%
Craft effective prompts, implement structured output patterns, and apply prompt
engineering techniques for production Claude applications.

### 4. Tool Design & MCP Integration — 18%
Design effective tool schemas, implement MCP servers and clients, and integrate
external services into Claude-powered applications.

### 5. Context Management & Reliability — 15%
Manage context windows effectively, implement caching strategies, handle long
conversations, and build reliable production systems.

---

## ⚠️ Do not confuse with the Associate exam

The **Associate – Foundations (CCAO-F)** is a different credential — $99, non-technical,
seven domains (evaluation, workflow design, governance), and it explicitly requires no
software-development or API experience. Both exams are 60 questions / 120 minutes / 720
to pass, which is why they get conflated. This workshop targets the **Architect**.

## Source caveat

These weightings come from third-party prep sites, not from Anthropic directly. The
authoritative blueprint lives in the Anthropic Partner Academy, partly gated behind
Claude Partner Network membership. Confirm before treating the drill questions in this
workshop as precisely calibrated.
